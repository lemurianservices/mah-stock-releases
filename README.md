# MAH STOCK
### Développé par MAH Services

Logiciel Windows de gestion pour l’hôtellerie et la restauration.

## Télécharger
Utilisez uniquement l’installateur de la [dernière version publiée](https://github.com/lemurianservices/mah-stock-releases/releases/latest).

## Mises à jour
La version 0.1.9 introduit les mises à jour intégrées. Les versions antérieures nécessitent une première installation manuelle de cette version.

Le logiciel recherche les nouvelles versions lorsque la connexion Internet est disponible. L’utilisateur choisit **Télécharger**, puis **Installer et redémarrer** après avoir terminé ses opérations. Une sauvegarde locale est créée avant installation. Le logiciel continue de fonctionner hors connexion.

Le fichier téléchargé doit correspondre au manifeste signé par MAH Services et à son empreinte de contrôle. Aucune base client n’est envoyée à ce dépôt.

## Version pilote
Tester sur un premier poste avant un déploiement général et conserver les sauvegardes. L’installateur ne possède pas encore de certificat Authenticode Windows. Les contrôles Windows restent actifs.

Ce dépôt contient les installateurs, leurs manifestes et les notes de version. Le code source du projet XENO reste privé.
